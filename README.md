# 项目简介

本系统是一款基于C语言的航空公司售票系统，旨在提供一个简洁、高效的航班信息查询与售票服务。

## 核心功能

- 浏览航班信息
- 航班查询
- 输入新航班信息
- 订票
- 退票
- 浏览已售票信息
- 数据保存与载入
- 系统退出

## 适用场景

适用于航空公司内部管理、客户自助购票、航班信息查询等场景。

## 技术特点

- 使用C语言开发，具有良好的稳定性和可移植性。
- 界面简洁，操作流程清晰易懂。
- 数据存储结构合理，便于查询和管理。
